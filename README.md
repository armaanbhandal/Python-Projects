# Python Projects

Python programs from my programming coursework: file processing, string manipulation, dictionaries and sets, simple encryption, and two larger projects (a memory-match game and a text-file word analyzer).

Requires Python 3. No third-party packages. Run each program from inside its own folder so it can find its data files:

```bash
cd project-02
python3 Project02_Q01.py
```

## Project 02

| File | What it does |
|---|---|
| `Project02_Q01.py` | Memory-match card game on a 4×4 board, with input validation |
| `Project02_Q02.py` | Compares two text files: unique, common, union, difference and exclusive words, plus word-frequency tables. Writes `fileAnalysis.txt` |
| `Project02_ExtraCredit.py` | Menu-driven contact book (look up, add, change, delete) saved to `contacts.txt` |
